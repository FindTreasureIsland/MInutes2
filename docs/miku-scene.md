# 初音未来到时场景

在“计时器 → 到时场景 → 初音未来”选择，右键菜单和状态栏也包含同一个选项。场景偏好使用独立键 hatsuneMiku，保留其他场景偏好。

素材为用户确认的“初音未来-原重绘版-仅去背景及碎片.gif”，原样复制至 Resources/HatsuneMiku.gif：560×560、12 帧、690ms、透明背景。未重新绘制、重排、缩放或对齐 GIF 源文件中的像素。

- ImageIO 一次解码并缓存帧，通过 Core Animation 按原帧时长循环播放。
- 一个提醒只显示一个角色，位于触发番茄钟所在屏幕；沿用覆盖所有桌面空间的提醒窗口配置。
- 从屏幕顶部沿水平中线进入，无弹跳和随机旋转。根据屏幕大小调整显示尺寸；计算所有帧的实际可见边界，透明边距不会影响落点。
- 显示倒计时：角色停在数字上方并保留间距；不显示倒计时：角色的可见区域居中。
- 双击淡出并结束休息，停止当前音乐；原有重复计时规则生效。单击和鼠标移动不会结束休息。
- 系统开启“减少动态效果”时，显示第一帧并淡入，保留相同落点与双击操作。

几何验证覆盖普通、4K 和小尺寸屏幕；原生离屏检查覆盖单角色、GIF 帧时长、两种落点以及双击结束回调。构建脚本和 Xcode 工程均包含 GIF 资源。
