# 使用统计界面设计

依据 ui-ux-pro-max 的玻璃质感、信息层级、渐进展示和无障碍建议，结合现有 Minutes2 圆盘及关于窗口设计。

- 680×285 原生窗口，透明标题栏保留系统关闭按钮，背景采用 HUD 毛玻璃，前景遮罩透明度为 22%，保留明显的背景模糊。
- 产品 Logo 与圆形专注主卡沿用圆盘的视觉语言，完成次数复用计时器的矢量数字；青色对应工作，橙色对应休息，灰色对应其他时间。
- 使用系统圆润字体，主指标 21–34pt，正文 11–12pt，次要说明 11pt。正文和指标使用适配明暗外观的颜色。
- 概览以今天的数据为主：主圆显示今日完成次数，大号文字显示今日工作时长及休息次数、时长，累计统计在对应位置以次要文字显示。
- 概览、趋势、热图三个原生分段 Tab；周期改为下拉选择，详细表格和统计口径按需打开。
- 数据区统一使用透明背景，去掉概览指标、趋势图和热图的独立填充及边框，直接融入窗口毛玻璃；通过留白、图例和字体层级区分信息。保留 20pt 外边距、12pt 分组间距，概览采用左右布局，近半年热图采用单条横向网格。
- Tab/筛选切换使用 180ms 淡入，遵循系统减少动态效果；减少透明度时关闭渐变背景，改用实色背景。
- “每日明细”和“统计说明”采用无底色、无边框的次要文字按钮，11pt 常规字重与小图标，悬停时文字加深，保留原生键盘焦点。
- 原生控件保留键盘焦点与辅助功能名称；每个图表提供可读取的数据表替代，热图提示也可通过数据表获取。
- 实际统计口径、持久化与计时行为保持原实现。
