# Minutes2 · 原生 macOS 番茄钟

Swift + AppKit 实现，支持 macOS 13 及以上。新应用与 `Minutes_x86` 中的原版独立，原版未作修改。

## 打开应用

双击 `build/Minutes2.app`。可将应用拖入“应用程序”文件夹。

## 操作

- 拖动圆周上的彩色圆点，顺时针设置 1–60 分钟；滚轮和方向键也可微调。
- 圆内的大数字在剩余时间超过 60 秒时显示分钟（向上取整）；进入最后一分钟后自动切换为 60、59、58…1 秒，并显示“秒”单位。暂停时保留当前秒数，调整回超过一分钟后恢复分钟显示。设时界面仍显示分钟。上方显示预计结束时间。
- 大数字使用按参考图绘制的原生矢量字形，笔画为圆润端点，带白色与半透明白色段；分钟和秒数使用相同样式。
- 100% 基准按对照图校准：左侧原版 Minutes 约 300 像素，右侧 Minutes2 约 316 像素，因此相对校准前的基准缩小约 5.06%。圆盘直径为 150.38 点，窗口为 220.56 × 220.56 点。
- 第一次单击圆盘只选中番茄钟并显示背景阴影；有阴影时再次单击圆盘开始、暂停或继续。点击圆盘外或其他窗口，阴影消失，计时状态不变；重新点击时先恢复阴影，再次点击才操作计时。空格 / Return 仍可直接开始、暂停、继续。
- 选中后的背景阴影加深并扩大模糊范围，呈现柔和的散开边缘。点击选中、开始、暂停、重置，以及调整时间时，背景色和玻璃透明度以约 0.45 秒的缓动动画过渡；连续操作从当前显示的颜色接续变化。
- 暂停时恢复玻璃背景并显示时间圆点，可在选中状态拖动它重新设定剩余分钟；调整后保持暂停，再次单击圆盘继续。滚轮和方向键也可在暂停时调整。
- 设时时呈现桌面玻璃模糊；倒计时颜色对应实际剩余时间：60 分钟蓝色、45 分钟绿色、30 分钟黄色、15 分钟橙色、0 分钟红色，各节点间按秒平滑插值。白色圆弧以 60 分钟为满圆；设时圆点使用相同颜色刻度。
- 音乐按钮使用矢量音符，悬停时为白色圆底和镂空音符，平时为白色音符与透明背景。单击在圆盘内打开采用原生毛玻璃背景的横向图标选择器：六种不同颜色依次对应禅音、溪流、安静、空灵、秋天、轻快，另有静音和自选音乐。鼠标移到音乐图标时自动试听，移到静音图标则停止播放；左右键或点击两侧图标切换也会自动试听，Enter 或点击中央图标确认；Esc 或点击圆盘外取消。静音使用划线音符，自选使用音符＋文件夹，确认后可选择 MP3、M4A、WAV 或 AIFF 文件。菜单中的“到时音乐…”也打开圆盘内选择器。
- 按住圆盘约 0.35 秒后拖动即可移动窗口，光标变为抓手，松开后固定并保存位置。长按或移动不会开始、暂停或继续计时，未选中时也可长按移动。时间圆点仍用于调整分钟数。按 Esc 重置。
- 鼠标悬停时不显示额外文字或关闭按钮。Command-H 可隐藏应用；菜单栏计时器可重新显示、设置预设时间及窗口置顶。
- 到时主窗口隐藏，透明提醒层叠加在各屏幕的当前桌面上，音乐循环播放。彩色泡泡每 0.45 秒随机出现一个，以弹出、放大和回弹动画进入，持续保留。泡泡分别以粉色、蓝色、黄绿色、青色、紫色和橙色为主，保留半透明球面、薄膜光泽及柔和白色高光。双击时播放水泡破裂音效，并显示球面膨胀、碎片散开和淡出动画；音效播放期间提醒音乐继续，待水泡音效和动画结束后再停止音乐、结束提醒。每个屏幕中央显示白色矢量格式的休息倒计时（分:秒）。移动鼠标、单击或按键不会结束提醒；双击结束休息、停止音乐并返回设时状态。休息自然结束时，未开启 重复计时 返回设时，开启 重复计时 自动开始下一轮完整番茄钟。
- 视图 → 大小提供 150%、120%、100%、80%、50%，当前默认尺寸为 100%。只缩放当前番茄钟，保持圆心位置，圆盘、字体、玻璃和操作区域同步缩放。比例自动保存，供下次启动和新建窗口使用。
- 视图 → 透明度提供 100%、75%、50%、25%、0%，设置当前番茄钟的整体可见程度。100% 完全显示，0% 完全透明且不阻挡桌面点击；计时和到时提醒仍然正常运行。通过顶部视图菜单可恢复透明度，必要时点菜单栏计时器中的“显示番茄钟”先激活应用。选项自动保存，供下次启动和新建窗口使用。
- 顶部菜单为 Minutes2 / 计时器 / 视图 / 窗口 / 帮助。计时器 提供计时控制、预设时间和音乐；视图提供“大小”“透明度”“保持在前台”和彩球提醒预览；窗口可居中和置顶窗口；帮助 提供使用说明。“保持在前台”与窗口置顶共享开关状态，并自动保存。右键菜单底部提供“退出 Minutes2”，Command-Q 也可退出应用。

## 计时器 菜单

菜单操作作用于当前选中的番茄钟；每个窗口独立计时、暂停、重复和选择音乐。关闭最后一个窗口后，仍可从菜单新建。 顶部 计时器 → 休息时间可选择 5、10、15、30 分钟，默认 5 分钟并自动保存；此选项不出现在右键菜单或菜单栏计时器菜单中。当前休息开始时确定时长，修改设置作用于后续休息。

| 菜单项 | 快捷键 |
| --- | --- |
| 新建番茄钟 | ⌘N |
| 关闭番茄钟 | ⌘W |
| 开始计时 / 暂停计时（保留剩余时间） | 空格 |
| 重复计时 | 点击切换勾选 |
| 1 / 3 / 5 Minute(s) | ⌘1 / ⌘3 / ⌘5 |
| 10 / 20 / 30 / 50 / 60 Minutes | ⌥⌘1 / ⌥⌘2 / ⌥⌘3 / ⌥⌘5 / ⌥⌘6 |
| 重置计时 | ⌘R |

运行中的预设时长会变灰；暂停后可以修改。重复计时 在休息倒计时自然结束后开始完整的下一轮，双击提前结束休息则返回设时状态。

## 构建与测试

需要 Xcode 或匹配 macOS SDK 的 Swift 开发环境，无第三方依赖。

```sh
cd /Users/crio/Downloads/Minutes
bash scripts/test.sh
bash scripts/build.sh
open build/Minutes2.app
```

构建脚本生成 ARM64 + x86_64 Universal 应用，并进行本机 ad-hoc 签名。可使用 Xcode 打开 `Minutes2.xcodeproj`，选择 Minutes2 scheme 后运行，内置音乐随工程打包。也可打开 `Package.swift`；直接以 `swift run` 运行时，AppKit 界面可用，但内置音乐须通过已打包的 `.app` 加载。

`Sources/MinutesCore` 包含计时状态、角度换算和颜色插值；`Sources/Minutes2` 包含原生窗口、玻璃效果、音乐选择和多屏提醒。`Tests` 验证真实时间截止、暂停恢复、延迟唤醒、圆周刻度和颜色。

计时用真实截止时间而非累减秒数；系统休眠后唤醒会检查是否已到时。运行期间申请防止空闲自动休眠，手动合盖 / 休眠仍由系统控制。上次分钟数、音乐和置顶选项自动保存，计时会话不跨应用退出恢复。

默认到时音乐来自 `music` 目录中的 MP3，随应用打包；默认选择“禅音”（原音乐 1），也可在音乐菜单中切换。原有晨光、风铃、轻柔选项会迁移至新默认音乐；已选择的自选音乐或静音设置保留。原版 `.music.bin` 没有作为可播放音频复用。

此构建为本地签名，未使用 Apple Developer 证书签名或公证；对外分发前需完成正式签名和公证。

应用图标参考原版 Logo，圆形以外为透明背景，圆内采用珊瑚红渐变与白色圆框。M 与右下角数字 2 均使用矢量路径绘制，笔画可见底部齐平，圆形 Logo 尽量填满图标尺寸；运行时 Dock 图标颜色与白色进度弧随番茄钟同步变化，多个运行窗口优先跟随当前选中的窗口，否则跟随最先到时的窗口。无运行计时器时恢复默认图标；`Resources/Minutes2Logo.svg` 为可编辑的矢量源文件，`scripts/make-icon.swift` 生成各尺寸 PNG 和 ICNS。

生成图标时，将 `scripts/make-icon.swift` 作为 main.swift，与共享绘制源 `Sources/Minutes2/MinutesLogo.swift` 一起编译。应用图标与 ICNS 生成器共用同一组矢量路径。
